# ✍️ How to Take Smart Notes

The method, compressed. Read this when you're unsure what to do with something.

## The decision tree

```
Encountered something interesting
        │
        ├─ Is it actionable right now? ──── yes ──> task in Daily Note or a Project
        │
        ├─ Is it about a specific source? ─ yes ──> 05_Notes/Literature (or 04_Resources/Books)
        │
        ├─ Is it an idea I want to keep? ── yes ──> 05_Notes/Fleeting, then distill to Permanent
        │
        ├─ Is it a thing I don't know? ──── yes ──> 05_Notes/Questions
        │
        └─ Is it just reference material? ─ yes ──> 04_Resources
```

## Anatomy of a good Permanent note

| Property | Bad | Good |
|---|---|---|
| Title | "Habits" | "Habits form around cues, not willpower" |
| Length | 3 pages | ~1 screen |
| Voice | quoted | yours |
| Links | 0 | 2+ |
| Standalone? | needs the book | readable alone in 5 years |

## The four failure modes

1. **Collector's fallacy** — saving ≠ knowing. Highlighting a book feels like learning and isn't.
2. **Over-structuring** — spending Sunday reorganizing folders instead of writing notes.
3. **Copy-paste** — the words must go through your own head or nothing is encoded.
4. **Write-only memory** — never rereading. Schedule the reread; that's where insight lives.

## The one question to ask on every note

> **"What does this connect to?"**

If nothing — either you don't understand it yet, or you don't actually need it.

## Progressive summarization (for long sources)

1. Capture the passage
2. **Bold** the parts that matter
3. ==Highlight== the bold parts that *really* matter
4. Write an executive summary at the top in your own words
5. Only then: extract Permanent notes

Do layers 1–2 while reading. Layers 3–5 only when you return to the note for a reason. Never do all five up front — that's busywork.
