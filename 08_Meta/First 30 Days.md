# 🗓 First 30 Days — how to make this stick

> Tracking your work too? Run [[08_Meta/Work-Style/First 30 Days (Work)|First 30 Days (Work)]] alongside this plan. It adds one habit per week and never more than five minutes a day.

Most vaults die in week two, not because the structure was wrong but because someone tried to do all of it on day one. Do this instead.

## Week 1 — capture only
Goal: build the reflex of writing things down. Nothing else.

- [ ] Install Obsidian, open this folder as a vault
- [ ] Install **Templater**, **Dataview**, **Calendar**, **Periodic Notes**
- [ ] Set the settings listed in [[START-HERE]]
- [ ] Write a Daily Note every day. Even three lines counts.
- [ ] Throw everything into `00_Inbox` without organizing
- [ ] Do **not** reorganize folders this week

**Success = 5 daily notes.** Nothing more.

## Week 2 — process
- [ ] Do your first Weekly Review (30 min, Sunday)
- [ ] Empty the Inbox to zero
- [ ] Write your first 3 Literature notes from whatever you're reading
- [ ] Fill in 3 Area notes — just "current state" and "the standard"

**Success = Inbox at zero once.**

## Week 3 — distill
- [ ] Write 5 Permanent notes, each in your own words, each linked to 2 others
- [ ] Create 1 project note for something you're actually doing
- [ ] Add 3 people to `06_People`
- [ ] Write 3 open Questions

**Success = 5 Permanent notes that make sense without their source.**

## Week 4 — express + review
- [ ] Do the Monthly Review
- [ ] Produce **one thing** out of your notes: a post, a summary, a decision, a taught explanation
- [ ] Prune: delete notes that aren't earning their space
- [ ] Adjust the system — remove anything you didn't use even once

**Success = one output that came from the vault.**

---

## Rules for staying alive past day 30

1. **Lower the bar on bad days.** A one-line daily note keeps the streak; a skipped day kills it.
2. **Never reorganize instead of writing.** Folder-fiddling is procrastination wearing a productivity costume.
3. **Delete aggressively.** Value comes from density, not volume.
4. **If a template annoys you, cut sections out of it.** These are yours now.
5. **The weekly review is the keystone.** If you keep exactly one habit, keep that one.

## What "getting smarter" actually looks like here

It's not the note count. It's these, measured monthly:

- Can I explain more things clearly than last month?
- Have I changed my mind about anything, with reasons?
- Do I ask sharper questions?
- Did I *use* a note I wrote months ago?
- Did I produce something someone else found valuable?

If those trend up, the system works. If only the note count trends up, you're hoarding — go back to [[08_Meta/MOCs/How to Take Smart Notes]].
