Daily notes live here, named YYYY-MM-DD. Created by the Daily Notes / Periodic Notes plugin using `08_Meta/Templates/T - Daily Note`. Steer the day, log what happens, reflect at night.

The 💼 Work log block in the template holds login, logout and the time log. Delete it on days (or in a vault) where you don't track work. Work Style reads everything in this folder; see `08_Meta/Work-Style/Work Style Guide`.
