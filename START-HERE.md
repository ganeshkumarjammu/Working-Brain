# 🧠 Second Brain — Start Here

This vault has one job: **turn what you encounter into what you can use.**
Everything else is filing.

---

## The 4 verbs (this is the whole system)

| Verb         | Where                                       | What it means                                                                          |
| ------------ | ------------------------------------------- | -------------------------------------------------------------------------------------- |
| **Capture**  | `00_Inbox`                                  | Get it out of your head in <10 seconds. No organizing.                                 |
| **Organize** | `02_Areas` / `03_Projects` / `04_Resources` | Move it to where it will be *used*, not where it "belongs".                            |
| **Distill**  | `05_Notes/Permanent`                        | Rewrite in your own words. One idea per note. This is the step that makes you smarter. |
| **Express**  | `03_Projects` / `04_Resources`              | Ship something: code, writing, a decision, a taught explanation.                       |

If you only ever do **Capture → Distill**, you will still get smarter every week.
Most people fail because they capture and never distill. Don't be most people.

## The folders

```
00_Inbox/          Everything lands here first. Empty it weekly.
01_Journal/        Daily, Weekly, Monthly, Yearly notes. Your logbook + reviews.
02_Areas/          Life domains with no end date (Health, Career, Money...).
03_Projects/       Things with a finish line and a deadline.
04_Resources/      Reference material by topic (Books, Articles, Mental Models...).
05_Notes/          The actual brain: Fleeting → Literature → Permanent + Questions.
06_People/         One note per person who matters.
07_Archive/        Finished or dead. Never delete, just archive.
08_Meta/           Templates, MOCs, Dashboards, Attachments.
```

**Projects vs Areas** — the single most useful distinction:
- *"Run a half marathon by December"* → Project (it ends)
- *"Fitness"* → Area (it never ends)
Projects live inside an Area's orbit and get archived when done. Areas are maintained forever.

## 05_Notes — the part that actually builds intelligence

1. **Fleeting** — raw sparks. Messy. Delete or promote within a week.
2. **Literature** — notes *about a source* (a book, paper, video). Always in your own words. Always with the source linked.
3. **Permanent** — one atomic idea, written as a full sentence claim, linked to at least 2 other notes. These compound.
4. **Questions** — open loops you're actively curious about. A vault full of good questions beats a vault full of good answers.

**The rule that makes it work:** a Permanent note must be understandable in 5 years by someone who never read the source. If it isn't, it's a Literature note.

## Daily loop (10 min)

1. Open today's Daily Note (`Ctrl+P` → Daily notes)
2. Set **3 outcomes**. Not 10. Three.
3. Log as you go: wins, blockers, ideas, what you learned
4. Before bed: 2 minutes on Reflection

## Weekly loop (30 min, Sunday)

1. Empty `00_Inbox` to zero
2. Promote the best Fleeting notes → Literature or Permanent
3. Review every Active project: still alive? next action?
4. Fill out the Weekly Review note
5. Pick **one** thing to do differently next week

## Monthly loop (60 min)

1. Review all 10 Areas — which are you neglecting?
2. Archive dead projects honestly
3. Monthly Review note
4. Re-read last month's Permanent notes — the reread is where connections happen

- Daily: `2026-08-03`

## Plugins to install (Settings → Community plugins)

**Essential**
- **Templater** — powers every template in `08_Meta/Templates` (dates, prompts, auto-fill)
- **Dataview** — powers every dashboard in `08_Meta/Dashboards`
- **Calendar** — click a day, get its note
- **Periodic Notes** — wires up Daily/Weekly/Monthly/Yearly properly

**Strongly recommended**
- **Omnisearch** — search that actually finds things
- **Excalidraw** — think visually; drawing beats writing for structure
- **Advanced Tables** — makes markdown tables bearable
- **Style Settings** + a theme (Minimal / Border) — you'll open it more if it looks good

**Optional but powerful**
- **QuickAdd** — one hotkey to capture to Inbox from anywhere
- **Spaced Repetition** — turn Permanent notes into flashcards. This is the "get smarter" cheat code.
- **Kanban** — visual project boards
- **Git** — version + backup your vault

## Tag vocabulary (keep it small on purpose)

```
#type/permanent  #type/literature  #type/fleeting  #type/question
#area/health  #area/mind  #area/career  #area/money  #area/relationships
#area/skills  #area/systems  #area/creativity  #area/self  #area/home
#status/active  #status/waiting  #status/someday  #status/done
#priority/high
```

Folders say *where it lives*. Tags say *what it is* and *what it's about*. Links say *how it relates*.
Don't invent a new tag when a link would do.

---

## The three habits that compound

1. **Write the note in your own words.** Copy-paste teaches you nothing.
2. **Link every new note to two existing notes.** Forced connection is where insight lives.
3. **Reread and revise old notes.** A second brain that only grows is a landfill. One that gets *pruned* is a garden.
